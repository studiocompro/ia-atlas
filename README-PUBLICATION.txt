IA ATLAS — VERSION PRÊTE POUR GITHUB PAGES

1. Créez un dépôt GitHub public nommé par exemple : ia-atlas
2. Décompressez le ZIP fourni.
3. Ouvrez le dossier ia-atlas-site.
4. Envoyez LE CONTENU du dossier à la racine du dépôt GitHub :
   index.html, data/, assets/, ia/, categorie/, scripts/, .github/, etc.
5. Dans GitHub : Settings > Pages > Source : GitHub Actions.
6. Le workflow .github/workflows/deploy-pages.yml reconstruira les fiches depuis les JSON puis publiera le site.

MISES À JOUR FUTURES
- data/ias.json : fiches IA
- data/prix.json : prix et dates de vérification
- data/gpu.json : cartes graphiques
